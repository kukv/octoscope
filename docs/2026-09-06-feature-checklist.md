# octoscope 機能チェック表

コードから抽出した現時点(Phase 2 取り込み後)の全機能。実機で 1 つずつ確認するための表。

判定は `OK` / `NG` / `-`(未確認)。NG のときは「何が起きたか」を一言書く。

確認コマンド:

```bash
go run ./cmd/octoscope                      # カレントのリポジトリ
go run ./cmd/octoscope --repo kukv/octoscope
go run ./cmd/octoscope --lang ja            # 桁ずれ確認
```
