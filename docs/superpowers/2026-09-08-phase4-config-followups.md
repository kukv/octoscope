# 設定ファイルスライスの積み残し

`config.Repositories` を入れたスライス（PR #69）のレビューで見つかったが、
そのブランチでは直さなかったもの。**直さないと決めた理由も書く。**

## 見つかったが直していないこと

### タブ行が ja の 80 桁で折り返すことがある

リポジトリ判定のタイムアウト警告（`tab.repo_lookup_timeout`）と設定の警告
（`tab.config_unreadable`）が両方立つと、ja の 80 桁でタブ行が 89 桁になり折り返す。
文言を縮めてもなお残る。

**直さなかった理由:** 設定ファイルが壊れていて、かつ `gh repo view` が 20 秒で
返らないという組み合わせは稀である。描画側でどちらかの警告を切ると、今度は
「立っているのがどちらの警告か分からない」という別の問題を招く。golden も
この組み合わせでは録っていない。

## 実端末での確認

設定ファイルの実端末での確認は 2026-09-08 に利用者が実施済み。日本語表示・
ASCII グリフ・Repos タブ起動・壊れた設定のときのタブ行の警告を、実際の端末で見て
問題なしと判断された。TTY の無い環境では代行できないため、以後のスライスでも
同じ受け渡しが要る。
