# api の応答本文とログのエントリに大きさの上限を入れる（#154）

## 問題

api バックエンドは、応答の本文を大きさの上限なしでメモリに読む。

- `internal/github/api/transport.go` の `exchange` は、本文を `io.ReadAll` で丸ごと読む。REST・GraphQL・
  ログの zip・ジョブ単体のログ、api の読み取りはすべてここを通る
- `internal/github/api/joblog.go` の `readEntry` は、zip の中のログ 1 件を `io.ReadAll` で丸ごと展開する
- ジョブログを開くと、run の zip 全体・展開したログ 1 件・画面に出す `[]github.LogLine` の 3 つが同時に
  メモリに載る

`walkPages` の `maxPages` のような歯止めがこの経路には無い（`docs/superpowers/2026-09-13-phase4-actions-followups.md`
「run のログアーカイブを丸ごとメモリに載せており、大きさの上限が無い」）。

## 根拠にする数字（利用者が決めたこと: 新しくは測らず、以前の記録を使う）

2026-10-18 の #152 の実測で、38 ジョブの matrix run の zip が 9〜18 MB だった（`gh run view --job --log`、
キャッシュ無しで 10.8〜21.2 秒。`docs/superpowers/plans/2026-10-18-cli-gh-timeout.md`）。他人のリポジトリに
改めてアクセスはしない。自分のリポジトリには、これより大きい run が無い。

## 方針（利用者が決めたこと）

- 上限は **128 MiB**。記録の最大 18 MB の 5 倍強を 2 の累乗に切り上げた値にする。余裕の取り方は、#152 で
  cli のジョブログの時間上限を決めたときの「18 MB の 5 倍強の zip まで切らない」と同じ。2 の累乗への
  切り上げは `responseTimeout` に合わせる。テストで小さくできるよう `var` にする
- `exchange` は本文を `上限 + 1` バイトまでしか読まない。超えたら、上限の値を含む分かるエラー
  （例: `read answer: larger than 128 MiB`）を返す。`ErrTransient` を包まないので、`readURL` は聞き直さない
  （大きさは聞き直しても変わらない）
- `readEntry` も、展開したログ 1 件に同じ上限を掛ける。zip は約 5 倍に圧縮されるので、zip が上限より
  小さくても、展開したログは上限を超えうる
- エラーは今の取得の失敗と同じ扱いで、ジョブログの画面に 1 行出る。TUI は触らない

やらないこと:

- 一時ファイル化。画面に出す行はどのみちメモリに載るので、zip をファイルに逃がしても、上限が無い問題は
  消えない
- `[]LogLine` の件数の上限。展開したログを上限で抑えれば、行もそれで抑えられる

## タスク

各タスクは、まず失敗するテストを書き、実装して緑にし、検証している行を一時的に壊してテストが落ちることを
確かめてから戻す（`.claude/rules/testing.md`）。

1. **応答本文の上限。** `api.go` に上限の `var` を置き、`exchange` で掛ける。テスト（`httptest`、上限を
   小さくする）:
   - 本文が上限ちょうどなら、そのまま読める
   - 上限 + 1 バイトなら、上限の値を含むエラーになる
   - そのとき 1 回しか聞かない（`read` の経路で、聞き直さない）
2. **ログのエントリの上限。** `readEntry` で同じ上限を掛ける。テスト: zip の中のログ 1 件が上限を超えると、
   `JobLog` が分かるエラーを返す。zip 全体は上限より小さく作り、エントリの上限が効いていることを確かめる
3. **ドキュメント。** followups の該当項目に、根拠にした数字・上限の決め方・#154 で片付いたことを追記する
4. `make check`（lint の出力が `0 issues.` であることも見る）
5. 実際に起動して確かめる。`--api --repo kukv/octoscope` で CI のジョブログを開き、今までどおり出ることを
   見る（`--lang ja`）。上限を超える場合は、手元だけ上限を小さくしたバイナリで、ジョブログの画面に
   エラーが 1 行出ることを見る。他人のリポジトリは使わない
