# Work: 盤面より下のホイールを無視する（#137）

## 問題

`work/mouse.go` の `handleMouseWheel` は `columnAt(msg.X)` しか見ず、Y を確かめない。
ドロワー・通知行・キーバーの上でホイールを回すと、その X にある列のカーソルが動く。
設計 §4.0「ドロワー上のホイールは何もしない」に反する。

## 方針

`handleMouseWheel` の先頭で、`msg.Y >= m.boardTop() + m.boardHeight()`
（盤面の最終行より下）なら何もしない。`cardAt` と同じく View が描く寸法
（`boardTop` / `boardHeight`）を読むので、ヒットテストがずれない。

盤面より上（1 列ずつめくるときの「列 2/4」の注記）は範囲外——Issue は下側だけを
指しており、そこで列が動いても設計に反しない。

2. `handleMouseWheel` にガードを足して緑に。既存のホイールのテストが通ること
3. `make check`。golden は不変（描画は触らない）
